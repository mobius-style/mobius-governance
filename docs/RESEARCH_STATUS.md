# Research status

## Protected N800

The protected N800 comparison is prospective and has not run. No protected
case text, label, prediction, outcome, or paper efficacy data is included in
this repository.

The intended design is 800 paired cases, 400 fault and 400 benign, each run
once under a strong baseline (C3) and the candidate condition (C5), for 1,600
planned condition executions. Execution remains blocked until independent data
custody, rights/privacy review, contamination checks, exact condition binding,
environment freeze, append-only authorization custody, external timestamp,
independent review, and exact owner authorization all exist.

## Statistical boundary

The prospective primary estimand is paired risk difference
`mean(C5 - C3)`, negative favoring C5. The design uses exact two-sided McNemar,
a fixed 5,000-replicate shared stratified paired bootstrap, predeclared P1→P2
gatekeeping, and Holm correction for the secondary family. These are protocol
facts, not results.

## Paper status

A methods/protocol package can be drafted now. An efficacy paper cannot be
written as if protected results exist. Historical development and prior failed
or invalid evaluations remain provenance/limitations evidence only and cannot
be promoted into protected N800 findings.
